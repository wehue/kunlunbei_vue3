## 工艺路线管理模块开发计划

### 1. 工艺路线管理列表页面 (`process_route_manage_info/index.vue`)

**功能实现：**
- 多条件查询：工艺编号、工艺路线名称、所属产品、审核状态
- 列表展示字段：工艺编号、工艺路线名称、所属产品、版本、审核状态、操作时间
- "显示所有版本"开关
- 新增工艺路线按钮（跳转到新增页面）
- 查看详情、提交审核、导出功能

**权限控制：**
- 设计师：可新增、查看、修改（已驳回状态）、提交审核
- 主管：可查看、审核（通过/驳回）
- 管理员：仅可查看

### 2. 工艺路线管理详情页面 (`process_route_manage_detail/index.vue`)

**功能实现：**
- 版本切换器
- 查看工艺路线详情：
  - 基本信息：工艺编号、工艺路线名称、所属产品、工艺描述、版本、创建时间、操作时间、审核状态、驳回原因
  - 工艺流程顺序：可拖动排序的流程步骤列表，每个步骤包含设备使用情况、操作人员、物料BOM
- 修改工艺路线（仅设计师，已驳回状态可修改）
- 提交审核按钮（修改后可点击）
- 审核功能（主管角色）

### 3. 新增工艺路线页面 (`process_route_manage_add/index.vue`)

**功能实现：**
- 基本信息：工艺编号（自动生成）、工艺路线名称、所属产品（选择）、工艺描述
- 工艺流程顺序：
  - 可拖动排序的流程步骤
  - 每个步骤可选择：设备、操作人员、物料BOM
  - 可查看关联内容的详情
- 保存、取消按钮

### 4. 数据结构设计

```javascript
// 工艺路线数据结构
{
  id: Number,
  routeCode: String,        // 工艺编号
  routeName: String,        // 工艺路线名称
  product: String,          // 所属产品
  description: String,      // 工艺描述
  version: String,          // 版本号
  isCurrent: Boolean,       // 是否当前版本
  status: String,           // 审核状态：pending/approved/rejected
  rejectReason: String,     // 驳回原因
  processSteps: [           // 工艺流程顺序
    {
      id: Number,
      stepName: String,     // 步骤名称
      order: Number,        // 顺序
      devices: [],          // 设备使用情况
      operators: [],        // 操作人员
      bomItems: [],         // 物料BOM
    }
  ],
  operationTime: String,    // 操作时间
  createTime: String,       // 创建时间
  baseId: String,           // 用于版本管理
}
```
