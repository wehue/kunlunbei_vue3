## BOM管理模块开发计划

### 1. BOM管理列表页面 (`bom_manage_info/index.vue`)

**功能实现：**

* 多条件查询：物料清单名称、版本号（模糊查询）

* 列表展示字段：清单编码、物料清单名称、版本号

* "显示所有版本"开关（默认关闭，仅显示当前有效版本）

* 多版本图标提示（BOM有多个版本时显示🔄图标）

* 新增BOM弹窗：

  * 基本信息：清单编码（自动生成）、物料清单名称、版本号

  * 父物料选择：从物料管理中选择已有物料

  * 子物料添加：选择物料 + 填写数量 + 绑定工序

* 查看详情、单个导出、批量导出功能

**数据结构设计：**

```javascript
// BOM数据结构
{
  id: Number,
  bomCode: String,         // 清单编码
  bomName: String,         // 物料清单名称
  version: String,         // 版本号
  isCurrent: Boolean,      // 是否当前有效版本
  parentMaterial: Object,  // 父物料
  childMaterials: [        // 子物料列表
    { 
      materialId, 
      materialName, 
      materialCode,
      quantity, 
      process 
    }
  ],
  baseId: String,          // 用于版本管理
}
```

### 2. BOM管理详情页面 (`bom_manage_detail/index.vue`)

**功能实现：**

* 版本切换器：顶部下拉选择框，可切换查看不同版本

* 查看BOM详情：

  * 基本信息：清单编码、物料清单名称、版本号

  * 父物料信息：物料编号、物料名称、规格型号

  * 子物料列表：物料编号、物料名称、数量、工序

* 编辑BOM信息：修改后自动生成新版本

* 版本历史时间线

* 返回、导出功能

### 3. 关联数据

* 物料数据：从物料管理模块获取已有物料

* 工序数据：从工序管理模块获取已有工序

* 版本管理：与物料管理一致，修改关键属性自动生成新版本
