## 物料管理模块开发计划

### 1. 物料列表页面 (`material_manage_info/index.vue`)

**功能实现：**
- 多条件查询：版本号筛选、物料分类、物料名称（模糊+精确查询）
- 列表展示字段：物料编号、物料名称、版本号、分类、位置
- "显示所有版本"开关（默认关闭，仅显示当前有效版本）
- 多版本图标提示（物料有多个版本时显示🔄图标，悬停提示版本数量）
- 新增物料弹窗：物料编号、物料名称、规格型号、库存数量、供应商、版本号、分类、位置
- 查看详情按钮

**数据结构设计：**
```javascript
// 物料数据结构
{
  id: Number,
  materialCode: String,    // 物料编号
  materialName: String,    // 物料名称
  version: String,         // 版本号（如 V1.0, V2.0）
  isCurrent: Boolean,      // 是否当前有效版本
  specModel: String,       // 规格型号
  stockQuantity: Number,   // 库存数量
  supplier: String,        // 供应商
  category: String,        // 分类
  location: String,        // 位置
  versionCount: Number,    // 该物料的版本总数
}
```

### 2. 物料详情页面 (`material_manage_detail/index.vue`)

**功能实现：**
- 版本切换器：顶部下拉选择框，默认显示当前版本，可切换查看历史版本
- 查看物料详情：展示所有字段信息
- 编辑物料信息：修改后保存时自动生成新版本
- 返回、导出功能

**版本管理逻辑：**
- 禁止删除历史版本
- 修改关键属性（规格、供应商、技术参数）保存时自动生成新版本
- 版本号自动递增（V1.0 → V2.0）

### 3. 模拟数据

- 物料分类选项：钢材、铝材、铜材、塑料件、电子元件
- 位置选项：仓库A、仓库B、仓库C、生产线
- 供应商选项：供应商A、供应商B、供应商C
- 包含多版本物料示例数据
