## 工序管理模块开发计划

### 1. 工序管理列表页面 (`process_manage_info/index.vue`)

**功能实现：**
- 多条件查询（工序编号、工序名称 - 模糊匹配）
- 工序列表展示（工序编号、工序名称、生产步骤）
- 新增工序弹窗，包含：
  - 基本信息：工序编号（自动生成）、工序名称、生产步骤描述
  - 生产和检测设备：可添加多个设备，选择设备名称、填写设备支出数量（关联设备管理）
  - 操作人员：选择操作人员（关联操作人员管理）
  - 时间信息：开始时间、结束时间（非必填）
  - 物料BOM：可添加多个物料，选择物料名称、填写物料支出数量（关联物料管理）
- 查看、导出功能

### 2. 工序管理详情页面 (`process_manage_detail/index.vue`)

**功能实现：**
- 查看工序详情：展示所有字段信息
- 编辑工序：可修改所有字段
- 返回、导出功能

### 3. 数据结构设计

```javascript
// 工序数据结构
{
  id: Number,
  processCode: String,      // 工序编号
  processName: String,      // 工序名称
  productionStep: String,   // 生产步骤描述
  devices: [                // 生产和检测设备
    { deviceId, deviceName, quantity }
  ],
  operators: [String],      // 操作人员列表
  startTime: String,        // 开始时间
  endTime: String,          // 结束时间
  materials: [              // 物料BOM
    { materialId, materialName, quantity }
  ]
}
```

### 4. 关联模块模拟数据

- 设备数据：使用设备管理的 mock 数据
- 操作人员数据：创建模拟操作人员数据
- 物料数据：创建模拟物料数据
