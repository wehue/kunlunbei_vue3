## 物料分类管理模块开发计划

### 1. 物料分类管理页面 (`material_category/index.vue`)

**功能实现：**

* 树形结构展示分类（使用 Element Plus 的 el-tree 组件）

* 分类层级示例：

  * 电子元器件

    * 无源分立元件

      * 磁性元件

        * 贴片电感

        * 功率磁环

        * 互感器磁芯

      * 电阻

      * 电容

    * 有源器件

  * 机械零件

    * 紧固件

    * 传动件

* 新增分类：选择父级分类，输入分类名称

* 修改分类：修改分类名称

* 删除分类：只能删除末级分类（无子节点的分类）

**权限控制：**

* 管理员：查看、新增、修改、删除

* 主管：查看、新增、修改（无删除权限）

* 设计师：仅查看

**数据结构设计：**

```javascript
// 分类数据结构
{
  id: Number,
  label: String,      // 分类名称
  parentId: Number,   // 父级ID（0表示顶级）
  level: Number,      // 层级
  children: []        // 子分类
}
```

### 2. 修改物料管理中的分类选择

**修改文件：**

* `material_manage_info/index.vue`：新增物料时的分类选择

* `material_manage_detail/index.vue`：编辑物料时的分类选择

**修改内容：**

* 分类选择下拉框只显示末级节点（叶子节点）

* 使用树形选择器（el-tree-select）展示分类层级

* 过滤掉有子节点的分类
